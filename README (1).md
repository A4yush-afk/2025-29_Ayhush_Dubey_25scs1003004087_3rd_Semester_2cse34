## 💻 Practical Project — TaskFlow

### TaskFlow – Responsive Task Management Dashboard

**TaskFlow** is a browser-based task-management dashboard created as a practical web-development project.

The application allows users to:

- Add new tasks.
- Enter task titles and descriptions.
- Set task priority.
- Set due dates.
- Mark tasks as completed.
- Undo completed tasks.
- Delete tasks.
- Filter tasks using **All, Pending, and Done** views.
- View basic dashboard statistics.
- Track the completion rate.
- Switch between light and dark modes.
- Preserve task information using browser **LocalStorage**.
- Use the application across different screen sizes through responsive design.

### Project Technologies

`HTML5` · `CSS3` · `JavaScript ES6` · `LocalStorage` · `DOM API`

```text
               │
               ▼

│       DOM Interaction       │

└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│       Data Persistence      │
│       Browser Storage       │
│        LocalStorage         │
└─────────────────────────────┘
```

The application does not require a server-side backend or cloud database. Task information is stored locally in the user's browser.

## 📊 Key Features

### Task Management
Create, complete, undo and delete tasks through a simple dashboard interface.

### Priority & Due Dates
Tasks can contain priority information and a due date to help organize work.

### Task Filtering
Users can switch between:

- **All**
- **Pending**
- **Done**

### Dashboard Statistics
The dashboard provides basic task statistics, including total, pending and completed tasks, along with completion percentage.

### Local Persistence
Task information is saved in browser LocalStorage so that it can be restored after refreshing the page.

### Responsive Design
The interface is designed to adapt to desktop, tablet and mobile screen sizes.

### Dark Mode
A dark-mode interface is available for improved viewing in low-light environments.
